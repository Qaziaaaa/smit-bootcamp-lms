BOOTCAMP LMS MASTER PROJECT PLAN

PROJECT OVERVIEW - Admin + Student based Bootcamp LMS. - Admin manages
students, attendance, teams, projects and tasks. - Students have
read-only access to their own profile, attendance, tasks, team and
assigned project.

USER ROLES

1.  ADMIN

-   Secure Login
-   Dashboard
-   Manage Students
-   Manage Attendance
-   Manage Teams
-   Manage Projects
-   Manage Tasks
-   Search & Filtering
-   Reports
-   Logout

2.  STUDENT Can:

-   Login
-   View Dashboard
-   View Profile
-   View Attendance History
-   View Attendance Percentage
-   View Assigned Team
-   View Assigned Project
-   View Assigned Tasks
-   Track Task Progress

Cannot: - Edit Attendance - Edit Tasks - Edit Projects - Access Other
Students - Access Admin Features

CORE MODULES - Authentication - Dashboard - Students - Attendance -
Teams - Projects - Tasks - Student Portal

HIGH LEVEL WORKFLOW Student Joins → Admin Registers Student → Assign
Batch → Assign Team → Assign Project → Daily Attendance → Daily Tasks →
Progress Tracking → Completion

SYSTEM FLOW Browser → React Frontend → Express API → Authentication →
Controller → Service → MongoDB → Response
